# Lagos Transport Data Explorer 🚦

## About the Project

This project explores transport-related data relevant to Lagos using Python
and data-analysis techniques.

The project is part of my journey into data analytics, artificial intelligence
and digital public services.

## 🎯 Project Objectives

The goal is to practise:

- Working with real-world datasets
- Cleaning and preparing data
- Exploratory data analysis
- Data visualisation
- Identifying useful patterns and trends
- Communicating findings clearly

## 🛠️ Technologies

This project will progressively use:

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Git & GitHub

## 📊 Analysis

The analysis will explore questions such as:

1. What patterns are present in the data?
2. What trends can be identified?
3. Are there unusual observations?
4. What insights could be useful for transport planning or public services?
